# Development Log

Dated notes describing what happened during a development session — not permanent system documentation.

File naming: `YYYY-MM-DD.md` (e.g. `2026-08-28.md`).

If a log entry uncovers a lasting technical decision or important discovery, copy that knowledge into the relevant note under `02 - Systems/` (or `07 - Technical/` once that folder exists) and keep the log entry itself as the historical record.
