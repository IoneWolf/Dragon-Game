# 2026-08-29

## Player Movement: Wall Sticking
- Investigated the player sticking to walls while holding left/right into a wall.
- Decided the first fix should be a zero-friction `PhysicsMaterial2D`, not a new wall layer or wall script.
- Existing editor tool: **Tools -> Dragon Adventure -> Generate No-Friction Physics Material 2D** creates `Assets/Physics/NoFriction.physicsMaterial2D`.
- Apply `NoFriction.physicsMaterial2D` to the Player's `Collider2D` Material field and the environment collider's Material field (`TilemapCollider2D` or `CompositeCollider2D` if the tilemap uses one).
- A wall layer is only needed later for wall-specific gameplay logic like wall sliding, wall jumping, ledge grabbing, or enemy wall checks.
- If sticking or upward popping still happens after applying the material, check `PlayerController.HandleSnag`: the anti-snag nudge may need to ignore cases where the player is pushing into a real wall.

## Camera: Vertical Limits
- Added optional vertical camera limits to `CameraFollow`.
- New inspector fields: `useVerticalLimits`, `topLimit`, and `bottomLimit`.
- When enabled, the camera follows the player normally on X, but clamps its Y center between the bottom and top values before smoothing.

## Music: Startup Playback
- Added `Assets/Resources/Music` as the project music folder.
- Added `GameMusicPlayer`, a startup/background music component for a normal scene object.
- If a `startupMusic` clip is assigned in the Inspector, it plays that clip; otherwise it loads the first `AudioClip` from `Assets/Resources/Music`.
- Music loops by default, uses adjustable volume, and persists between scenes by default.
- Moved `Soundtrack derg game.mp3` into `Assets/Resources/Music` so it auto-plays when Level 1 starts.
- Removed the editor menu creator after assembly-reference issues; the preferred setup is now a manually created scene object with `GameMusicPlayer` attached.
- Added an Add Component menu label for `GameMusicPlayer` so it can be found under **Dragon Adventure/Audio/Game Music Player**.
- Added explicit startup loading for `Assets/Resources/Music/Soundtrack derg game.mp3` before falling back to any other music clip in the folder.
- Updated the soundtrack import settings to preload audio data and import as 2D audio.
- Final setup uses a manually placed `GameMusicPlayer` object in `Level 1.unity` with an `AudioSource` referencing `Soundtrack derg game.mp3`.
